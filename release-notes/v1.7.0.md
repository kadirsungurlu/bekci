## Bekci 1.7.0

### Türkçe

**Yenilikler**
- **Salt okunur API anahtarı:** Ayarlar → API anahtarları → Erişim: Salt okunur. Yalnız sunucu, envanter, sunucu olayı, sertifika, monitör ve olay okuma uçlarına erişir; yeni uçlar `GET /api/certs`, `GET /api/server-events`. Var olan anahtarlar tam erişimli kalır.
- **Varsayılan veritabanı PostgreSQL + TimescaleDB:** örnek compose `timescale/timescaledb:2.31.0-pg18` kullanır. Ölçümler sıkıştırılır, grafikler özetlerden gelir, eski veri otomatik silinir.
- **`uptime migrate`:** SQLite'tan PostgreSQL'e taşıma komutu. İlerleme gösterir, kesilirse kaldığı yerden devam eder, sonunda her tablonun satır sayısını doğrular. SQLite dosyasını değiştirmez.
- **Ayarlar → Genel uyarısı:** SQLite ya da eklentisiz PostgreSQL kullanıyorsanız uyarı şeridi gösterilir.
- **Gece yedeği:** uygulama imajına `pg_dump` eklendi; `DATABASE_URL` ile de `.dump` yedeği alınır.
- **Canlı topoloji:** yeni Topoloji sayfası paneli, kontrol noktalarını, monitörleri, sunucuları, bildirim kanallarını ve açık olayları tek ekranda canlı gösterir; olay kartı neden ve bildirim kayıtlarını açıklar. Dar ekranda liste görünümüne geçer.
- **Sunucu envanteri:** ajan servisleri, konteynerleri, dinleyen portları, SSL sertifikalarını ve disk bölümlerini toplar; sunucu sayfasına Envanter sekmesi eklendi. Gizli bilgi toplanmaz, komut satırındaki parolalar maskelenir. `INVENTORY=0` ajanda kapatır. Windows'ta yalnız disk bölümleri.
- **Sertifika bitiş uyarısı:** sertifika bitişine 14/7/1 gün kala olay ve bildirim (Ayarlar > Genel, sertifika başına yoksayma).
- **Sunucu olayları:** sunucu sayfasına Olaylar sekmesi: yeniden başlatma, OOM, servis ve konteyner değişimleri, port, uyarılar.
- **Disk dolma tahmini:** sunucu sayfasında ve listede; 7 gün altında uyarı ve bildirim (eşik ayarlanır). Hızlı disk dolumu uyarısı (varsayılan 60 dakikada 5 puan).
- **Uzun grafikler:** grafiklere 1 yıl aralığı ve günlük özet eklendi.

**Kullanımdan kalkıyor (sonraki büyük sürümde kaldırılacak)**
- **SQLite:** bu sürümde çalışır, açılışta uyarı verir. `uptime migrate` ile taşıyın.
- **Gömülü PostgreSQL imajı (`:postgres`, `Dockerfile.postgres`):** bu sürümde yayınlanır, açılışta uyarı verir. Dökümle varsayılan kuruluma geçin.

**Değişmeyen**
- **Düz PostgreSQL (RDS vb.):** eklenti yoksa çalışır, uyarı verir. Önerilmez; büyük ölçekte yavaşlar.

**Yükseltme**
- SQLite kullananlar: `docker compose run --rm bekci migrate`. Rehber: https://bekci.app/docs/veritabani/
- Bu sürüme geçmek zorunlu olarak taşıma gerektirmez; mevcut kurulum olduğu gibi açılır.
- Eski ajan yeni panelle, yeni ajan eski panelle uyumlu çalışır.
- Geri dönüş: SQLite dosyası değişmez, eski etikete dönülebilir. Taşımadan sonraki veri SQLite'ta yoktur.
- Düz PostgreSQL ve gömülü imajdan geçişte tablolar panelin ilk açılışında dönüşür; panel bu sırada kapalıdır (1,2 milyon satırda 26 sn - 2,5 dk).
- Sıkıştırma açıkken ham veri saklaması gün sınırında uygulanır, süre en çok 1 gün uzayabilir.

### English

**New**
- **Read-only API key:** Settings → API keys → Access: Read-only. It reaches only the server, inventory, server event, certificate, monitor and incident read endpoints; new endpoints `GET /api/certs`, `GET /api/server-events`. Existing keys keep full access.
- **PostgreSQL + TimescaleDB is the default database:** the sample compose uses `timescale/timescaledb:2.31.0-pg18`. Measurements are compressed, charts read rollups, old data is removed automatically.
- **`uptime migrate`:** moves SQLite data to PostgreSQL. Shows progress, resumes after an interruption and verifies every table's row count at the end. It doesn't change the SQLite file.
- **Settings → General notice:** a warning strip appears when you run on SQLite or PostgreSQL without the extension.
- **Nightly backup:** `pg_dump` is now in the application image, so `.dump` backups also work with `DATABASE_URL`.
- **Live topology:** the new Topology page shows the panel, check locations, monitors, servers, notification channels and open incidents on one live screen; the incident card explains the reason and the notification records. It switches to a list on narrow screens.
- **Server inventory:** the agent collects services, containers, listening ports, SSL certificates and disk partitions; server pages gain an Inventory tab. No secrets are collected and passwords on command lines are masked. `INVENTORY=0` turns it off on an agent. On Windows, disk partitions only.
- **Certificate expiry alerts:** incident and notification 14/7/1 days before a certificate expires (Settings > General, ignore per certificate).
- **Server events:** server pages gain an Events tab: reboots, OOM, service and container changes, ports, alerts.
- **Disk full forecast:** on the server page and in the list; alert and notification under 7 days (adjustable). Fast disk growth alert (default 5 points in 60 minutes).
- **Longer charts:** charts gain a 1 year range with daily rollups.

**Deprecated (removed in the next major version)**
- **SQLite:** works in this version with a startup warning. Move with `uptime migrate`.
- **Embedded PostgreSQL image (`:postgres`, `Dockerfile.postgres`):** still published in this version, with a startup warning. Move to the default setup with a dump.

**Unchanged**
- **Plain PostgreSQL (RDS, etc.):** without the extension it runs and shows a warning. Not recommended; it slows down at large scale.

**Upgrading**
- SQLite users: `docker compose run --rm bekci migrate`. Guide: https://bekci.app/en/docs/database/
- Upgrading doesn't force a migration; an existing install starts as before.
- Old agents work with the new panel, and new agents work with the old panel.
- Rollback: the SQLite file is unchanged, so you can return to the old tag. Data written after the migration isn't in SQLite.
- Upgrading from plain PostgreSQL or the embedded image converts tables on the panel's first start; the panel is down meanwhile (26 s to 2.5 min for 1.2 million rows).
- With compression on, raw data retention applies at day boundaries, so data may stay up to 1 day longer.
