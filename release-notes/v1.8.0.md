## Bekci 1.8.0

### Türkçe

**Yenilikler**
- **Canlı topoloji yenilendi:** sorun çizelgesi, sunucu, kontrol noktası, kanal ve monitör sütunları. Bir öğeye tıklayınca yalnız ilişkili olanlar kalır, bağlantılar çizgiyle gösterilir, ayrıntı şeridi açılır. Arama, "Yalnız sorunlular", gruplama, klavye kullanımı ve telefon görünümü var. 1000 monitörlük panelde akıcı çalışması için satırlar sanallaştırıldı.
- **Monitör ile sunucu bağı:** monitör formunda "Çalıştığı sunucu" alanı. Hedef kayıtlı bir sunucuyla eşleşirse öneri gelir.
- **Üst bilgi alanları:** kontrol noktalarına ve sunuculara rol, bölge, sağlayıcı ve kod yazılabilir; topoloji bunlara göre gruplar.
- **Kanal teslim sayaçları:** topoloji kanalların son gönderimini, son hatasını ve saatlik gönderim sayısını gösterir.
- **Betik çalıştırma (varsayılan kapalı):** imzalı betikleri sunucu ajanlarında onay akışıyla çalıştırma. Çevrimdışı imza aracı `bekci-imza`, yerel izin ve iğneleme (`uptime betik`), kurcalamayı belli eden kayıt, acil durdurma ve Betikler sayfaları. Ajanda açıkça etkinleştirilmeden hiçbir şey çalışmaz. Rehber: belgelerde Betik çalıştırma sayfası.

**Düzeltmeler**
- Web Push: anahtar değişince eski abonelik görünür, yeniden abone olurken değiştirilir.
- PWA güncelleme şeridi açık temada okunur.
- Telefonda taşan uzun IPv6 adresi ve küçük dokunma alanları düzeltildi.

**Yükseltme**
- Veritabanı şeması 47'den 50'ye geçer, işlem saniyeler sürer. Önce yedek alın; PostgreSQL'de otomatik migration yedeği alınmaz.
- Eski ajan yeni panelle çalışır.
- Şema yükseldikten sonra 1.7.0 açılmaz ("veritabanı sürümü yeni" hatası). Geri dönüş: yükseltme öncesi döküm geri yüklenir, sonra eski etiket kullanılır.

### English

**New**
- **Live topology rebuilt:** problem board plus server, check location, channel and monitor columns. Clicking an item keeps only what relates to it, draws the connections and opens a detail strip. Includes search, "Problems only", grouping, keyboard use and a phone layout. Rows are virtualised to stay smooth with 1000 monitors.
- **Monitor to server link:** a "Runs on server" field in the monitor form, with a suggestion when the target matches a registered server.
- **Metadata fields:** check locations and servers accept role, region, provider and code; the topology groups by them.
- **Channel delivery counters:** the topology shows each channel's last send, last error and hourly send count.
- **Script execution (off by default):** run signed scripts on server agents through an approval flow. Includes the offline signing tool `bekci-imza`, local permission and pinning (`uptime betik`), a tamper-evident log, an emergency stop and the Scripts pages. Nothing runs until it is explicitly enabled on the agent. Guide: the Script execution page in the docs.

**Fixes**
- Web Push: after a key change the old subscription is shown and replaced on re-subscribe.
- The PWA update bar is readable in the light theme.
- Long IPv6 addresses no longer overflow on phones; small touch targets were enlarged.

**Upgrading**
- The database schema moves from 47 to 50 in seconds. Take a backup first; PostgreSQL has no automatic pre-migration backup.
- Older agents work with the new panel.
- Once the schema is upgraded, 1.7.0 refuses to start ("database version is newer"). To roll back, restore the pre-upgrade dump, then use the old tag.
