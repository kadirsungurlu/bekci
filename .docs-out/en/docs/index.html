Getting started

What Bekci is, what you need, and which install path fits you. Decide in a few minutes and continue with the right guide.

On this page
  • What you need
  • Which install path fits you?
  • Which database?
  • A few terms
  • Help

Bekci watches your websites, APIs and servers from a single panel and tells you right away when something goes wrong. It runs on your own server as a single Docker image: the interface, the check engine, the database and the server agent binaries all ship in the same image.

These docs are written so that you can install Bekci end to end on your own, even if you are not very familiar with Linux and Docker. Every guide is a list of numbered steps, and each step ends with a “What you should see” box that tells you whether you are on track.

What you need#

MinimumRecommended
CPU1 vCPU1–2 vCPU
Memory (RAM)512 MB1 GB
Disk10 GB10 GB or more
CPU architectureamd64 (x86_64) or arm64 (aarch64)
Operating systemAny Linux distribution that can run DockerA current Ubuntu LTS or Debian release
  • Docker: Bekci ships as a Docker image. If Docker isn't installed yet, the first step of the Docker guide shows you how.
  • A domain (optional): to open the panel at a secure address such as https://bekci.example.com you need a domain (or subdomain). You don't need one to try Bekci out.
  • Memory use: Bekci itself uses about 15 MB of RAM with 10 monitors and 3 servers. With the database, 4 GB is recommended for 100 monitors (hardware).

Note

The commands in these docs assume you are logged in as root. If you connect to the server as another user, put sudo in front of the commands (e.g. sudo docker ps).

Which install path fits you?#

Find the row closest to your situation and open that guide. If you are unsure: if you have an empty server and a domain, choose the Caddy install. It gives you a secure (HTTPS), permanent setup with the least effort.

Your situationGuideTime
I just want to try it; I have a server with DockerDocker (one command)3 min
One server with Docker; I want the settings in a fileDocker Compose5 min
An empty server and a domain; I want HTTPSHTTPS install (Caddy) — recommended10 min
My server runs CoolifyCoolify5 min
My server already runs Nginx, Traefik, Apache or CaddyBehind a reverse proxy10 min

Are ports 80 and 443 taken?

If Coolify or another web server (Nginx, Apache…) already runs on your server, ports 80 and 443 are in use. In that case don't use the Caddy install; follow the Coolify or reverse proxy guide instead.

Docker (one command)Run one command and open it in your browser. The quickest way to try Bekci. Docker ComposeSettings live in one file; easier updates and backups. PostgreSQL + TimescaleDB. HTTPS install (Caddy)A complete setup on your own domain with an automatic Let's Encrypt certificate. CoolifyAdd it as a Docker image and let Coolify handle the domain and certificate. Behind a reverse proxyPut it behind your existing Nginx, Traefik, Apache or Caddy. First stepsAfter installing: your first monitor, notification channel and status page.

Which database?#

There is nothing to decide: new installs use PostgreSQL + TimescaleDB; the Docker Compose file starts the database too.

OptionStatusWhen
PostgreSQL + TimescaleDBDefaultAll new installs
Plain PostgreSQL (DATABASE_URL)Works, not recommended; slows down at large scaleManaged services such as RDS where the extension can't be installed
SQLite, embedded PostgreSQL (:postgres)Deprecated, removed in the next major versionExisting installs only

To move older installs and to choose hardware, see Database and migration.

A few terms#

Terms you will come across while using Bekci:

TermMeaning
MonitorA target checked at regular intervals: a website, an API, a port, a database, a cron job…
IncidentA period during which a monitor is down, recorded with its start, end and cause.
Status pageA public page showing your customers the state of your services.
Server agentA small program installed on a server you want to watch; it sends CPU, RAM, disk and network metrics.
Check locationA copy of Bekci that checks your monitors from another location (e.g. another city).
BASE_URLThe address the panel is reached at from outside. Links in notifications and agent install commands use it.

Help#

If you get stuck, start with Troubleshooting. If something in the docs is missing or wrong, or you found a bug, report it on GitHub. Bekci is open source (AGPL-3.0); the source code is on GitHub.

About the interface language

Bekci's panel is available in English and Turkish. Its server logs are written in Turkish; where these docs quote a log line, an English translation is given next to it.
